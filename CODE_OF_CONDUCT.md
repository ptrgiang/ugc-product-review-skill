# Code of Conduct

## Our standard

We want this project to be useful, welcoming, and technically rigorous.

Contributors should:

- be respectful and specific in technical disagreement
- critique ideas and implementations, not people
- keep issues and pull requests focused on reproducible behavior
- disclose AI-assisted contributions when material generation or review was performed by an AI agent
- avoid spam, self-promotion, harassment, discriminatory language, or intentionally misleading claims

## Maintainer responsibilities

Maintainers may edit, hide, close, or remove contributions that violate these expectations or that create unnecessary maintenance burden.

## Reporting

Report conduct concerns privately to the maintainer through the contact method on the maintainer's GitHub profile.

## Scope

This policy applies to repository issues, pull requests, discussions, review comments, and project-related community spaces.
