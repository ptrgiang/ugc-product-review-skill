# Contributor Ideas

Use this page to find focused improvements that can become small pull requests.

## Product categories

Potential modules:
- automotive accessories
- baby / parenting products
- fitness equipment
- travel accessories
- furniture
- stationery / office supplies

A category should be broad enough to reuse across many products and specific enough to change physical interaction or creative strategy.

## Evaluation fixtures

Useful fixtures pair a prompt with an expected production decision.

Examples:
- liquid product should preserve viscosity and fill level
- shoe try-on should preserve left/right geometry and lace layout
- appliance sequence should not jump from running back to sealed
- mirror shot should preserve wardrobe and product orientation

## Compatibility

Contributions can document verified activation/install behavior for coding agents not yet covered in `docs/COMPATIBILITY.md`.

## Real failure cases

The highest-value contribution is often a real generated-video failure with:
- input prompt
- observed defect
- error classification
- repaired instruction
- what improved after regeneration

Do not include copyrighted or private source assets without permission.
