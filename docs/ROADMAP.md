# Roadmap

This roadmap is intentionally contribution-friendly. Items should become focused issues and pull requests rather than one large rewrite.

## Near term

- Add more product categories with real interaction constraints.
- Add reproducible prompt-failure fixtures for hands, product morphing, reflections, liquids, and fabric.
- Add model-adapter examples backed by tested generations.
- Expand cross-agent activation smoke tests.
- Improve campaign novelty and feature-coverage examples.
- Add a compact evaluation dataset of prompt + expected production decisions.

## Good first contributions

These are deliberately small and self-contained:

- add one missing product category
- add one product-specific failure/repair example
- improve one category's physics or hand-interaction guidance
- add one compatibility note for a supported coding agent
- add one campaign example showing genuinely different angles
- improve validation error messages

## Medium projects

- Build a lightweight benchmark runner for structured prompt outputs.
- Add semantic checks for duplicate campaign concepts.
- Add optional structured output schemas for production systems.
- Add tested model-adapter profiles with versioned evidence.
- Add multilingual documentation and examples.

## Longer term

- Curate community-contributed real-world UGC failure cases.
- Publish a small evaluation corpus for product fidelity and UGC realism.
- Integrate with broader skill registries and discovery tools.
- Establish a documented compatibility test matrix across major coding agents.

## Non-goals

- becoming a monolithic prompt encyclopedia
- duplicating the same skill for every agent vendor
- hard-coding undocumented video-model behavior as fact
- maximizing prompt length

If you want to work on an item, open an issue first when the scope is more than a small isolated change.
