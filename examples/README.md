# Examples

These examples show the intended activation and routing behavior. They are deliberately small so contributors can add real product cases without bloating the canonical skill.

## Workflows

- [`minimal-product.md`](minimal-product.md) — one product to one autonomous review prompt
- [`campaign.md`](campaign.md) — diversified multi-video campaign
- [`repair.md`](repair.md) — diagnose a generated-video failure and repair the prompt

## Contributions wanted

A useful example contribution includes:

1. the user input or product context,
2. the intended module routing,
3. the expected creative decision,
4. the generated prompt or repair excerpt when useful,
5. the production failure being prevented.

Avoid examples that merely rephrase an existing example with a different product name.

High-value examples include difficult hands, liquid physics, clothing fit, mirrors, changing product geometry, product-state continuity, and campaign angle collisions.
