# FASHION-PUFFER-002 — Prompt V04

## Purpose

Reference-conditioned partial-state experiment. Unlike V03, this test assumes a supplied visual start frame showing the intended one-arm-in / one-sleeve-empty state.

```text
TITLE
Navy Puffer Fit Review — V04 Clip 1 — Reference-Conditioned Sleeve Insertion

INPUT PRIORITY
1. The supplied V04 start-frame image defines the exact opening body and garment state.
2. The original navy puffer reference defines jacket geometry, color, quilting, collar, zipper, cuffs, pockets, material, length, and proportions.
3. Previous successful clips define creator identity, room, daylight, and casual UGC character when needed.

OBJECTIVE
Generate one 8-second vertical 9:16 realistic smartphone UGC video that CONTINUES DIRECTLY from the supplied V04 start frame.

Do not reinterpret or recreate the opening pose. The first video frame must preserve the supplied start state: RIGHT arm already inside the right sleeve, LEFT arm outside the jacket, LEFT sleeve visibly empty.

0:00–0:01.0 — PRESERVE START STATE
Almost no movement. The viewer must still clearly see right arm inserted, left arm outside, and left sleeve empty. No dialogue. No cut. No camera move.

0:01.0–0:05.8 — LEFT ARM ENTERS EMPTY LEFT SLEEVE
The creator slowly moves the LEFT hand into the existing left sleeve opening. Show continuously:
1. fingertips enter sleeve opening;
2. hand travels through sleeve;
3. forearm follows sleeve path;
4. elbow bends naturally;
5. fabric gathers around forearm;
6. hand emerges from left cuff.

The left sleeve remains connected to the left shoulder seam. The right side remains already worn. The right hand may lightly stabilize the jacket front, with no second complex action.

0:05.8–0:07.0 — SHOULDER SETTLE
After the hand exits the cuff, gently roll the left shoulder and allow the jacket to settle naturally. One small downward adjustment is acceptable. Keep jacket open.

0:07.0–0:08.0 — END-STATE HOLD
Both arms correctly inside sleeves, both hands outside cuffs, jacket open, product geometry unchanged.

CAMERA
Vertical 9:16 smartphone UGC, nearly static three-quarter framing, natural home daylight. No orbit, zoom, whip, rack-focus trick, or reframing that hides the sleeve action.

STRICTLY FORBIDDEN
- do not ignore or redesign supplied start frame
- do not begin fully worn
- do not place left arm inside sleeve before visible motion begins
- no cuts
- no creator disappearance
- no empty-room bridge frame
- no teleporting garment
- no sleeve swapping or detachment
- no arm passing through fabric
- no duplicate limbs/cuffs
- no hidden state jump behind body occlusion
- no quilt-pattern drift
- no zipper relocation
- no garment resizing

PASS CONDITION
Pass only if the first frame preserves the visual partial state, the left sleeve is visibly empty at the beginning, the left arm visibly enters that same sleeve, the left hand emerges from the correct cuff, and no hidden state jump occurs.
```

## Required setup

Use the intended partial-worn still as a true start-frame / initial-image input if the workflow supports it. If the image is supplied only as a general reference, this experiment is not equivalent to V04's intended test.
