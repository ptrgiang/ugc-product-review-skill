# FASHION-PUFFER-002 — V06A prompt

Status: **ready for generation — true first-frame-lock test**

## Experiment objective

Test one narrow hypothesis:

> Can the model preserve a real supplied partial-worn image as the literal first frame and continue only the missing left-sleeve insertion?

This branch requires an actual start-frame image. Do not run V06A if the workflow cannot use that image as the literal image-to-video first frame.

## Required input state

The supplied start image must show:

```text
same creator
same bedroom / daylight character
same navy quilted jacket
RIGHT arm fully inside right sleeve
RIGHT shoulder already seated
LEFT sleeve visibly empty
LEFT arm fully outside jacket
jacket open
left sleeve opening clearly visible
no ambiguous arm overlap
```

## Generation prompt

```text
Create one realistic 8-second vertical 9:16 smartphone UGC continuation from the supplied start-frame image.

The supplied image is the literal first frame of the video. Preserve that opening state exactly. Do not reconstruct any earlier dressing action.

Preserve the creator's identity, face, hair, body proportions, white fitted long-sleeve top, black wide-leg pants, white shoes, bedroom, daylight, and camera position.

Preserve the exact navy quilted jacket: color, quilting layout, silhouette, collar, zipper, sleeve length, cuffs, material, hem, scale, and proportions.

OPENING STATE — LOCK EXACTLY
At frame 1:
- RIGHT arm is already fully inside the right sleeve;
- RIGHT shoulder is already seated naturally;
- LEFT sleeve is completely empty;
- LEFT arm is fully outside the jacket;
- left sleeve opening is clearly visible and separate from the left hand;
- jacket remains open.

Do not show any earlier state.
Do not show the creator picking up the jacket.
Do not show both sleeves empty.
Do not show the right arm entering the jacket.
Do not reset to an unworn state.

0:00–0:01.0 — PRESERVE START STATE
Continue from the supplied image with almost no movement so the partial-worn state remains clearly readable.

0:01.0–0:05.5 — LEFT-SLEEVE INSERTION
The creator briefly looks toward the empty left sleeve opening.

She naturally guides only her LEFT hand into that existing sleeve opening and pushes the LEFT arm through in one continuous visible motion.

Show clear physical progression:
1. left fingertips enter the sleeve opening;
2. hand moves through the sleeve;
3. forearm follows the sleeve path;
4. elbow bends naturally;
5. padded fabric gathers and shifts around the arm;
6. left hand emerges from the correct cuff.

The RIGHT side remains already worn throughout.

The left sleeve stays attached to the left shoulder seam and retains constant length and geometry.

0:05.5–0:07.0 — SETTLE
After the left hand emerges, the creator gives one small natural shoulder adjustment and lets the padded jacket settle across both shoulders.

0:07.0–0:08.0 — END-STATE HOLD
Hold the fully worn jacket clearly for approximately one second.

Both arms are inside the correct sleeves, both hands are outside the cuffs, and the jacket remains open.

CAMERA
Static or nearly static vertical smartphone camera.
Three-quarter to full-body framing.
Natural bedroom daylight.
No zoom, orbit, dolly, whip, dramatic reframing, or camera move that hides the sleeve action.

AUDIO
Quiet room ambience and realistic fabric rustle only.

PERFORMANCE
Casual understated social-media try-on behavior.
No exaggerated smiling.
No commercial-model posing.

STRICTLY FORBIDDEN
- no unworn opening state
- no earlier dressing reconstruction
- no right-arm insertion
- no instant fully-worn teleport
- no jacket morphing
- no sleeve duplication
- no sleeve disappearance
- no sleeve detachment
- no sleeve-length change
- no arm clipping through fabric
- no extra fingers or limbs
- no hidden state jump behind body occlusion
- no hard cut
- no creator disappearance
- no zipper relocation
- no quilt-pattern drift
- no garment resizing
- no captions or logo card
```

## Pass condition

V06A passes only if all are true:

```text
1. frame 1 visibly matches the supplied start image
2. no unworn state appears
3. right arm never exits or re-enters the jacket
4. left sleeve is visibly empty at the beginning
5. left arm visibly enters that same sleeve
6. left hand emerges from the correct cuff
7. jacket geometry remains stable
8. no cut, teleport, or hidden state jump occurs
```

If condition 1 fails, classify the experiment as failed regardless of later motion quality.
