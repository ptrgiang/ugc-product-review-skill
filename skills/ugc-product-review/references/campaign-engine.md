# Campaign Engine

Load for multi-video campaigns, concept diversification, registries, or content planning.

## 1. Default batch logic

For 5 videos, aim for meaningful diversity:

1. Visual proof / hero demo
2. Problem → Solution
3. Skeptical / trust test
4. Lifestyle / routine
5. Curiosity / discovery

Adapt by category.

## 2. Collision prevention

Reject two concepts as duplicates if they share most of:
- first frame
- hook logic
- proof type
- hero feature
- emotional arc
- ending

Rewrite one concept.

## 3. Coverage map

Track:
- features already covered
- objections already covered
- hook types used
- hero moments used
- environments used
- funnel stages covered

Prioritize gaps.

## 4. Funnel roles

### Attention
Curiosity, result-first, unusual action.

### Consideration
Demo, routine, feature proof.

### Trust
Honest review, skeptical test, limitation.

### Conversion
Value, objection handling, who-it-is-for, soft CTA.

For 10-video campaigns, cover all four.

## 5. Creative saturation

If core angles are exhausted, do not generate weak duplicates.

Instead consider:
- objection content
- FAQ
- comparison
- audience-specific context
- new environment
- creator mode variation
- seasonal context

Use `templates/creative_registry.csv` when structured tracking is requested.

## 7. Batch quality gate

For 5 videos:
- at least 3 hook types
- at least 3 proof/narrative types
- at least 2 camera modes
- at least 2 emotional arcs
- avoid overusing one hero feature

## 8. Naming

`[PRODUCT] — [ANGLE] — [DURATION] — V##`
