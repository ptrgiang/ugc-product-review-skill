# Category: Appliances / Kitchen Machines

Use only for appliances, kitchen machines, and similar mechanical household products.

## Priorities
- setup sequence
- container/lid/control geometry
- mechanism
- process
- result transformation
- cleanup if relevant

## State examples
`outside → loaded → locked → running → finished → opened`

## Physics
Preserve:
- weight
- container support
- lid orientation
- button positions
- realistic motor response
- realistic contents level

## Hand guidance
Prefer:
- one hand stabilizes container/product
- one hand operates latch/button

Avoid:
- moving appliance while operating
- simultaneous complex rotation + camera movement

## Strong archetypes
- Skeptical → Impressed
- Fast Demo
- Problem → Solution
- ASMR Process
- Routine

## Hero moments
- mechanism starts
- transformation reveal
- pour
- spoon pull
- easy removal

## Negative constraints
- no extra buttons
- no changing control panel
- no floating container
- no lid morphing
- no changing appliance scale
- no impossible motor motion
