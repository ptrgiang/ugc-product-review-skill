# Category: Electronics / Gadgets

## Priorities
- actual use case
- controls
- ports
- geometry
- screen orientation
- mechanism
- setup simplicity

## Rules
Preserve:
- dimensions
- button/port placement
- cable orientation
- screen size
- physical thickness
- plausible UI

Do not invent functions.

## Strong archetypes
- Problem → Solution
- Hidden Feature / Discovery
- Skeptical Test
- Desk Routine
- Comparison
- Is It Worth It?

## Hero moments
- activation
- useful feature
- compact setup
- old-vs-new workflow

## Negative constraints
- no invented ports
- no UI teleportation
- no changing screen orientation
- no floating cable
- no device resizing
