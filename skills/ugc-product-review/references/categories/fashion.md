# Category: Fashion / Footwear / Bags

## Priorities
- fit
- material
- drape
- silhouette
- styling
- movement
- closure details

## State
`folded/boxed → held → tried on → worn/styled`

## Fashion rules
Preserve:
- sleeve/hem length
- seams
- zipper
- collar
- pockets
- quilting/panel layout
- hardware

## Footwear rules
Preserve:
- left/right correctness
- outsole geometry
- lace layout
- toe box
- sole proportions
- realistic flex

## Bags
Preserve:
- strap length
- closure
- pocket placement
- hardware
- capacity

## Strong archetypes
- Try-On
- Unboxing → Try-On
- First Impression
- Material Detail
- Expectation vs Reality
- Styling

## Hero moments
- mirror reveal
- side profile
- fabric compression/release
- walking flex
- what-fits-inside reveal

## Negative constraints
- no garment-length drift
- no missing sleeves
- no shifting zipper
- no shoe resizing
- no changing lace layout
- no impossible mirror geometry
