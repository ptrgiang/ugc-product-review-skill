# Core Rules

Use this module for every production task.

## 1. Product truth

Separate:

- visible facts
- user-provided facts
- reliably known facts
- creative assumptions

Never invent unseen features as facts.

When product confidence is:
- HIGH: use detailed product-specific actions.
- MEDIUM: use conservative actions.
- LOW: ask one focused clarification if function materially affects the concept.

## 2. Reference priority

Priority:
1. explicit user instruction
2. product reference
3. creator reference
4. reliable product information
5. category assumptions

If references conflict, do not silently merge variants.

## 3. Creator consistency

When a creator reference exists, preserve:
- face
- hairstyle
- complexion
- approximate age appearance
- body proportions
- wardrobe and accessories when continuity requires them

The creator should behave like a real person, not a commercial actor.

Prefer:
- small pauses
- glances at the product
- subtle eyebrow movement
- minor framing imperfections
- natural posture
- restrained reactions

Avoid:
- constant smiling
- presenter gestures
- excessive pointing
- perfect choreography
- exaggerated influencer acting

## 4. Product consistency

Preserve:
- geometry
- proportions
- color
- material
- logo placement
- controls
- openings
- packaging
- included accessories
- scale relative to hands and environment

Avoid:
- redesign
- recolor
- invented buttons
- moving logos
- size changes
- impossible state changes

## 5. Product-state continuity

Track valid state transitions.

Examples:

Appliance:
`outside → loaded → locked → running → finished → opened`

Fashion:
`folded → held → partially worn → worn`

Cleaning:
`dirty → product applied → wiped → clean`

Beauty:
`closed → opened → dispensed → applied`

Do not jump backward in state unless intentionally using another take.

## 6. UGC camera language

Default:
- vertical 9:16
- smartphone look
- natural window or practical light
- ordinary dynamic range
- slight exposure/focus correction
- mostly static or mild handheld movement
- one main environment per short video

Avoid cinematic movement unless requested.

## 7. Physical plausibility

Every action must respect:
- gravity
- weight
- contact
- hinges/latches
- material flexibility
- liquid viscosity
- human grip
- support surfaces

Use one primary action per shot when possible.

## 8. Dialogue

Dialogue should sound spoken.

Use:
- short sentences
- contractions
- pauses
- small reactions
- personal observations

Do not narrate what viewers already see.

Prefer:
hook dialogue → silent action → reaction dialogue.

## 9. Timing

Approximate speech capacity:
- 1s: 1–3 words
- 2s: 3–6 words
- 3s: 5–9 words
- 5s: 8–15 words

Do not cram dialogue into complex manual actions.

## 10. Realism guard

Avoid:
- warped hands
- extra fingers
- floating objects
- changing geometry
- plastic skin
- impossible reflections
- fake slow motion
- excessive background blur
- perfect studio composition
- over-staged environments

## 11. First-frame rule

Within the first 1–2 seconds show at least one:
- product
- problem
- result
- unusual action
- meaningful reaction

Avoid dead openings and generic greetings.

## 12. Hero moment

Each video should have one strongest visual proof.

Give it enough time to register, usually about 0.8–2.0 seconds.

Do not bury it in a montage.

## 13. Shot economy

Every shot must contribute:
- hook
- context
- proof
- product understanding
- emotional progression
- result
- verdict

Delete decorative shots that do not help the review.

## 14. Controlled imperfection

Use subtle imperfection only:
- tiny framing adjustment
- autofocus correction
- slight pause
- casual glance
- hand repositioning
- natural breath
- ordinary background details

Do not make footage intentionally sloppy.

## 15. Default North Star

The viewer should think:

"This looks like someone genuinely tried the product and filmed what happened."

Not:

"This looks like an AI-generated commercial."
