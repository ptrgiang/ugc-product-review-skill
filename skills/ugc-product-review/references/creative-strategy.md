# Creative Strategy Module

Load when selecting concepts, hooks, story structure, or creative angles.

## 1. Analyze the product

Determine:

### Interaction type
- Transformation
- Process
- Wearable
- Sensory
- Utility
- Feature-led
- Discovery / novelty

### Primary buyer motivation
Examples:
- saves time
- saves effort
- improves result
- convenience
- organization
- comfort
- appearance
- premium feel
- novelty
- replacement of old method

### Strongest visual proof
Prefer what can be shown quickly and understood without explanation.

### Strongest viewer doubt
Ask:
"What would a skeptical buyer question?"

Examples:
- Does it really work?
- Is setup annoying?
- Is it too bulky?
- Is material cheap?
- Is result exaggerated?
- Is it worth the money?

## 2. Choose a review archetype

Use the strongest fit, not the most fashionable format.

### Problem → Solution
Best for obvious recurring frustration.

### Skeptical → Impressed
Best for hype, novelty, or surprising performance.

### First Impression
Best for packaging, material, appearance, or first use.

### Unboxing → Test
Best when package reveal matters.

### Fast Demonstration
Best when function is visually obvious.

### Before → After
Best when result is visibly measurable.

### Everyday Routine
Best when convenience is the value.

### Social Proof
Best for trend-driven products.

### Discovery
Best for unusual or clever products.

### Feature Breakdown
Best when 2–3 functions matter equally.

### Is It Worth It?
Best when trust/value is the key question.

### Honest Review
Best when credibility matters more than spectacle.

### Comparison
Best when old method/product can be shown.

### ASMR / Satisfying
Best when mechanics, texture, or sound is strong.

### Try-On / Styling
Best for fashion, footwear, accessories.

## 3. Concept selection logic

Priority:
1. visible transformation
2. satisfying process
3. wearable result
4. unusual/viral mechanism
5. recurring problem
6. feature clarity
7. value/trust

## 4. Hook selection

Match hook to evidence.

### Result-first
Use when payoff is visually strong.

### Skeptical
Use when viewer may doubt hype.

### Problem
Use when frustration is obvious.

### Social proof
Use when trend matters.

### Curiosity
Use for unusual mechanisms.

### Sensory
Use for food, beauty, texture, sound.

Avoid generic:
- "Hi guys"
- "Today I'm reviewing..."
- "Let me introduce..."

## 5. First-frame design

Strong first frames:
- product already in use
- result close-up
- creator holding unusual outcome
- problem clearly visible
- product entering frame with a believable reaction

## 6. Emotional arcs

Examples:
- skeptical → curious → impressed
- frustrated → hopeful → relieved
- curious → delighted
- neutral → pleasantly surprised
- overwhelmed → organized
- uncertain → confident

Prefer subtle arcs.

## 7. Shot graph

Use the simplest useful graph.

General:
`HOOK → ACTION → PROOF → REACTION → VERDICT`

Transformation:
`BEFORE → PRODUCT → PROCESS → AFTER`

Fashion:
`HOOK → DETAIL → TRY-ON → MIRROR → VERDICT`

Utility:
`PROBLEM → PRODUCT → ACTION → RESULT`

Unboxing:
`PACKAGE → OPEN → REVEAL → TEST`

## 8. Creative scoring

Score candidates 1–5 on:
- Hook strength
- Visual proof
- Product clarity
- Emotional interest
- Authenticity
- Generation reliability
- Differentiation

Subtract complexity for:
- too many states
- difficult hands
- moving camera + detailed action
- multiple locations
- reflection dependence
- readable text dependence

Pick the highest-value reliable concept.

## 9. Alternative concepts

When useful, suggest 2–4 alternatives.

They must differ in more than dialogue.

Vary:
- hook
- proof
- emotional arc
- creator mode
- camera mode
- ending
