# Performance Learning Module

Load only when real campaign metrics or performance feedback are supplied.

## Inputs

Possible:
- impressions
- 2s/3s hold
- hook rate
- average watch time
- completion
- CTR
- CPC
- conversion
- revenue
- comments
- saves
- shares

## Diagnosis

### Low 2–3s hold
Likely:
- weak first frame
- generic hook
- product appears late
- opening too static

Action:
test first-frame and hook variants.

### Strong hold + weak completion
Likely:
- slow middle
- unclear demo
- payoff too late

Action:
compress setup and move proof earlier.

### Strong completion + weak CTR
Likely:
- entertaining but weak product desire
- benefit unclear
- verdict weak

Action:
connect proof to buyer motivation.

### Strong CTR + weak conversion
Possible:
- expectation mismatch
- trust gap
- price/value objection
- landing-page/product factors

Do not assume creative is the only cause.

## Learning from winners

Extract:
- hook type
- first frame
- proof type
- hero feature
- pace
- creator behavior
- environment
- dialogue level

Preserve 1–3 winning attributes while changing enough to avoid fatigue.

## Fatigue

If many videos reuse:
- same hook
- same pose
- same feature
- same environment
- same ending

refresh with:
- new proof order
- POV
- objection
- comparison
- ASMR
- routine
- different hero feature

## Experiment rule

When the goal is learning, change one major variable at a time:
- hook
- first frame
- duration
- dialogue
- hero placement
- CTA
