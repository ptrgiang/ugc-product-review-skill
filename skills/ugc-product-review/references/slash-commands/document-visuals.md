# Document / Presentation / Infographic slash presets

Use these presets for supporting explanatory assets when explicitly requested.

- `/specsheet` — Technical/product detail sheet with clear hierarchy and structured facts.
- `/infographic` — Convert information into a visual, easy-to-scan infographic.
- `/comparisonchart` — Compare options, features, or approaches in a readable visual structure.
- `/timeline` — Present events or stages along a chronological sequence.
- `/processdiagram` — Show a step-by-step process from start to finish.
- `/flowchart` — Show a decision or processing flow with clear branches and outcomes.
- `/mindmap` — Branch concepts from one central topic.
- `/presentationslide` — One presentation slide with strong hierarchy, minimal text, and clear visual focus.
- `/factcard` — Compact information card for one fact, metric, or short knowledge point.
- `/trainingvisual` — Visual aid for training, SOPs, workflows, or internal education.

## UGC integration notes

These presets are usually support outputs rather than core review-video outputs. Use them for product education, creator briefs, campaign planning, comparison support, or production documentation only when requested.

Never invent technical specifications, performance figures, prices, measurements, certifications, or comparison claims. If the needed facts are missing, mark placeholders or ask for the missing facts instead of fabricating them.
